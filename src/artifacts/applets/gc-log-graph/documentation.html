Processing Scripts

Utility scripts for pre-processing large log files before visual analysis.

  • Performance detect-gc-cms-churn.sh
    Detects high churn rate ParNew GCs using a sliding window calculation. Implemented in awk for extreme performance on large log files.
  • Log Extraction grep-multi-city-searches.sh
    Extracts multi-city search requests and matches them with their corresponding response lines (containing lastGoodsCount). Supports optional Travelport GDS (AP) filtering.
